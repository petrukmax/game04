# AGENTS — working rules for this repository

## Always re-export the web build

This project ships both a Godot desktop build and a browser build in `web/`.

**After any change to game code, scenes, resources or UI, always re-export the web version
before finishing the task.** The committed `web/` folder is a snapshot; if it is not
re-exported, the browser version keeps the old behaviour.

```powershell
$godot = "$env:LOCALAPPDATA\Temp\opencode\godot\Godot_v4.7.2-stable_win64_console.exe"
& $godot --headless --path . --export-release "Web" web/index.html
```

Checklist:

1. Make and verify the change in the desktop build.
2. Run the regression suite:
   `& $godot --headless --path . --fixed-fps 60 res://tests/TestRunner.tscn`
3. Re-export with the command above.
4. Confirm `web/index.pck` (and `web/index.js` / `web/index.wasm` if the toolchain changed)
   has a new timestamp.
5. Smoketest the browser build:
   `node tools/serve.mjs 8787` then
   `node tools/web-shot.mjs "http://127.0.0.1:8787/web/index.html" "tests/web_build_1600x900.png" 1600 900 4500`
   The canvas must appear and only the known `2D MSAA is not yet supported for GLES3`
   warning is acceptable.
6. `node tools/check-pages.mjs` must still PASS before publishing.

Do not hand-edit files inside `web/`; they are generated by the exporter.
